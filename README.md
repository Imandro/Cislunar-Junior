# Cislunar Junior

Simulador educativo Unity de misiones cislunares.

## Proyecto

El simulador está en [`CislunarJunior/`](CislunarJunior/).

1. Abre `CislunarJunior/` desde Unity Hub con Unity 6000.6.6f1.
2. Abre `Assets/Scenes/CislunarJunior.unity`.
3. Ejecuta la escena.

Consulta [CislunarJunior/README.md](CislunarJunior/README.md) para controles, build de Windows y detalles técnicos.

Última validación: build Windows correcta; 23 pruebas EditMode y 12 PlayMode pasan. La revisión visual manual confirmó plataforma, ascenso, cambio de atmósfera y separación en ventana 800×700.
